# EasyConnection

用 Android 手机查看和操作 Windows 电脑，也可以把常用操作保存为快捷流程。

## 安装与连接

1. 电脑运行 `EasyConnection.Host.exe`，手机安装 `EasyConnection-0.4.1.apk`（Android 7.0 及以上）。本地安装包分别在 `artifacts/windows` 和 `artifacts/android`。
2. 电脑端点击“复制手机连接信息”。
3. 在手机端粘贴，点击“连接此电脑”。配对成功后，下次打开可直接重连。

连接信息 5 分钟有效，过期后重新复制即可。电脑需要保持开机、登录并运行电脑端，手机与电脑的网络需要能够互通。

## 使用

桌面页提供两种模式：

- **实时控制**：画面持续更新，直接操作电脑。
- **单步查看**：每次操作后更新一张截图。

点击“横屏全屏”放大查看，双指可以缩放画面。在画面下方选择“点按”“右键”或“拖动”；长按画面也可以右击。鼠标微调区支持小幅移动和左右键，按住方向按钮可连续移动。

点击电脑上的输入框后，在手机弹出的面板中输入文字，再点“输入到电脑”。支持多行文字；需要发送或确认时，另点“Enter（发送/确认）”。没有自动弹出面板时，可以手动点“输入文字”。

常用操作可以保存为预置流程，在“快捷”页执行，在“任务”页查看结果。要在流程中打开软件，先在电脑端点击“注册可启动应用”。

## 缓存与连接排查

- 手机：**连接 → 手机缓存**，查看用量并清理手机缓存。
- 电脑：**高级设置与连接排查 → 电脑缓存与清理**，查看用量并清理电脑缓存。

连接不上时，先确认电脑端仍在运行，再点击电脑端的“检查本机连接”；需要放行防火墙时，点击“允许网络访问”。

关闭电脑端窗口后，程序会留在托盘运行。需要退出或更新时，右击托盘图标，选择“退出”。锁屏或电脑休眠时无法正常操作。
